# Scribbles

Scribbles is a full-stack blogging website that allows users to create, manage, and explore blogs. This platform integrates a dynamic frontend with a robust backend to provide a seamless user experience for both readers and writers.

---

## Features

### User Features:
- **Authentication**: Sign up and log in to personalize your blogging experience.
- 
- **Create Blogs**: Write and publish blogs with rich text formatting.
- 
- **Edit/Delete Blogs**: Manage your blogs effectively with editing and deleting options.
- 
- **Explore Blogs**: Browse blogs from various authors and categories.
- 
- **Commenting**: Engage with other blogs through comments.
- 
- **Search**: Easily find blogs by titles or keywords.

### Admin Features:

- **User Management**: Manage user accounts (add, edit, or delete users).
- 
- **Blog Moderation**: Approve, reject, or edit blogs submitted by users.
- 
- **Analytics Dashboard**: View site performance and user engagement metrics.

---

## Technologies Used

### Frontend:
- **React.js**: For building a dynamic and responsive user interface.
- 
- **Tailwind CSS**: For sleek and modern styling.
- 
- **Axios**: For making HTTP requests to the backend.
- 
- **React Router**: For navigation between pages.

### Backend:
- **Node.js**: Server-side runtime.
- 
- **Express.js**: Web framework for handling API routes.
- 
- **MongoDB**: Database for storing blogs and user data.
- 
- **Mongoose**: ORM for MongoDB.
- 
- **JWT**: For secure user authentication.
- 
- **Cloudinary**: For image storage and management.

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Sunny-Saurya/scribbles.git
   cd scribbles
   ```

2. Install dependencies:
   - **Frontend**:
     ```bash
     cd frontend
     npm install
     ```
   - **Backend**:
     ```bash
     cd backend
     npm install
     ```

3. Run the application:
   - Start the backend server:
     ```bash
     cd backend
     npm start
     ```
   - Start the frontend server:
     ```bash
     cd frontend
     npm start
     ```
